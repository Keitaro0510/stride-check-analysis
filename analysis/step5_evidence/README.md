## 5-2 予測モデルの比較と、論文の AUC の再現 ✅

### 目的
1. 予測の値を「タイプのケガの割合」と「変数をそのまま使ったモデル」のどちらで出すかを、同じ条件の評価で決める
2. 動画で測れる項目だけでケガをどこまで予測できるか、ケガ歴や練習量を足すとどうなるかを示す
3. npj 2026 の論文の AUC（約0.78）が、評価の分け方でどれだけ変わるかを示す

### スクリプト
| ファイル | 中身 |
|---|---|
| `ev_common.py` | パス、設定、ステップ3のモジュールの読み込み（ステップ3の `common` と名前がぶつからないようにしている） |
| `21_npj_prediction.py` | リズム（npj 2026、140名）：R0 予測なし／R1 タイプ／R2 変数そのまま（直線）／R2b（曲線）／R3 ＋ケガ歴／R4 ＋練習量・性別。人ごとの5分割×20回、罰則付き Cox 回帰 |
| `22_loh_prediction.py` | フォーム（Loh 2025、81名・137脚）：F0 予測なし／F1 タイプ／F2 変数そのまま／F3 ＋性別・年齢・週の走行距離／参考 膝の屈曲だけ。人ごとの5分割×50回、重み付きの罰則付きロジスティック回帰 |
| `23_npj_paper_replication.py` | 週ごとの行でランダムフォレスト。行をランダムに10分割（論文と同じ）と、人ごとに10分割を比べる |
| `24_report.py` | 決めておいた基準での判断、図、`prediction_report.md` |

### 判断（9/17 ユーザー了承）
- 決め方：変数そのままとタイプの AUC の差の信頼区間が0を含めば、変数そのままを採用。採用したモデルの AUC の信頼区間の下限が0.5を超えなければ、「予測の精度は低い」と明記する
- フォームにインソールのリズムは足さない。膝の屈曲だけのモデルは、事後に選んだ項目の参考として含める
- タイプのモデルは、交差検証の学習データごとにタイプを作り直す（方法とタイプの数はステップ3で採用したものに固定）

### 評価のやり方で気をつけたこと
- **C-index と AUC は、同じ分割の中の組だけで計算する。** 最初は全分割の予測をまとめて計算したが、分割ごとに学習データが違うので予測の水準がずれ、そのずれが「逆向きの予測」として数えられて、予測なしのモデルの AUC が約0.38になった。分割の中だけで比べるように直し、予測なしがちょうど0.5になることを確認した
- 左右差は、ステップ3のパーセンタイル（全員で順位を付けた値）ではなく、正規化された値をそのまま使った（順位付けにテスト用の人が混ざらないように）

### 結果の要点
- **リズム**：変数そのまま（AUC 0.58）とタイプ（0.59）は同程度 → 決め方どおり変数そのままを採用。ただし信頼区間が0.5を含み、**当てずっぽうより良いとは言えない**。予測は人によって78〜87%の範囲にしか分かれない
- **フォーム**：変数そのまま（AUC 0.64［0.52〜0.76］）がタイプ（0.51）より高い傾向（差の信頼区間は0を含む）→ 変数そのままを採用。**当てずっぽうよりは良い**。予測は21〜41%の範囲
- **ケガ歴・練習量を足しても良くならず、むしろ下がった**（リズム、フォームとも）
- **論文の AUC の再現**：行をランダムに分けると AUC 0.757（論文 0.781）だが、**人ごとに分けると 0.476** で当てずっぽうと同じ。論文の AUC は、同じ人の別の週が学習とテストの両方に入ったことで高めに出ていた可能性が高い

## 5-3 プロトタイプ用の予測モデルの書き出し ✅

`25_export_prediction_models.py` → `outputs/prediction_models.json`（確認：`outputs/prediction_models_check.txt`）

- 5-2 で採用した「変数そのまま」のモデルを全データで学習し直し、プロトタイプで同じ計算ができるように、式・係数・標準化の値を書き出した
  - リズム：罰則付き Cox 回帰（組み合わせBの6項目）。`risk = 1 − S0_52w ^ exp(Σ coef × (z − center))`
  - フォーム：重み付きの罰則付きロジスティック回帰（4つの角度）。`risk = 1 / (1 + exp(−(intercept + Σ coef × z)))`、脚ごと
- 罰則の強さは、5-2 の交差検証で最も多く選ばれた値（リズム penalizer 5.0、フォーム C 0.1）
- 書き出した式の予測は、lifelines・scikit-learn の予測と一致（最大差 1e-16）
- 項目ごとの影響（予測を上げるか下げるか）、人単位のブートストラップ200回の係数（予測の幅用）、5-2 で測った精度も含める
- リズムの左右差は npj の正規化値のままなので、動画で測った値をパーセンタイル経由で変換するための分位点の表（`asymmetry_quantiles`）も含める

### 結果の要点
- **リズム**：罰則が最も強い値に決まり、係数はほぼ0。予測は全員 80〜85%（参加者全体 84%）で、**実質的に「誰でもほぼ同じ」**という予測になる。5-2 の「当てずっぽうと区別できない」と一致
- **フォーム**：1SDあたりの係数は、膝の屈曲 −0.38（深く曲がるほど予測が下がる）、股関節の内転の値 −0.23、骨盤の傾き −0.14、膝の外反 −0.04。全データでの予測の範囲は 16〜68%（交差検証での予測の広がりは 21〜41% で、全データで学習したほうが広く出る）
- 骨盤の傾きは「骨盤が落ちるほど予測が下がる」向きで、よく言われる考え方とは逆。係数は小さく、確かな関係とは言えない
